# Corvus

AION 2 Global DPS meter (damage, healing, damage taken), character gear and alarms. Private builds for our party.

## Install

1. Install **Npcap** from https://npcap.com (default options). Corvus only listens to game traffic; it never sends
   anything to the game.
2. Download `Corvus.exe` from the latest release below and put it in its own folder (it keeps its data next to it).
3. Run the game in **borderless window** or **window** mode, then start `Corvus.exe`.

## Updates

Corvus checks this page every 6 hours. When a new version is out, a bar on top of the panel offers
**Install and restart**; settings and records stay. You can also use Settings → Advanced → Check now.

Every release has a `Corvus.exe.sha256`; the updater refuses a download whose SHA-256 does not match.
